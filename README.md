# USB Analyzer

A simple Python-based tool for scanning and analyzing USB storage devices.

USB Analyzer is a small project built with Python and Streamlit. Its goal is to collect basic information about USB devices and analyze files stored on them.

## Current Features

- Basic dashboard using Streamlit
- USB device information
- Storage capacity display
- Basic file scanning
- File format analysis (in development)

## Technologies

- Python
- Streamlit
- Linux `lsblk`
- JSON
- OS and pathlib modules

## Requirements

- Python 3
- Linux operating system
- Streamlit

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd "USB analyz"
```

Install Streamlit:

```bash
pip install streamlit
```

Run the application:

```bash
streamlit run app.py
```
